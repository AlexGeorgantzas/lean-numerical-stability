# Run HighamBench Formalization Experiments

## Frozen scope

Pilot 14 (`formalization-benchmark-pilot-14`) is a distinct successor. Every
Pilot-13 and earlier artifact is immutable predecessor evidence; never resume,
rewrite, or pool it with Pilot 14. Reuse the exact frozen library build and
single inherited task-neutral warm root. Never rebuild the unchanged library or
run another scout.

The allowlist contains H00-00; P01-T2, P02-T2, P03-T2, P13-T2, P14-T2; and
H22-11, H22-5, H20-6, H7-12, H20-9, H20-8, H23-6, H5-5, H10-7, H12-4,
H19-5, H7-14, H15-3. H00-00 is a synthetic infrastructure canary and never
scientific evidence.

One named-task request normally authorizes exactly one N/L pair. A multi-task
campaign is allowed only when the user explicitly names or authorizes it. The
current Pilot-14 primary campaign is frozen as H5-5, H7-12, H10-7, H23-6.

Every candidate must formalize the exact source result and give
`HighamBenchCandidate.target` a complete kernel-checked proof. Reject all proof
holes and trust escapes.

## Before any state mutation

Read [references/operations.md](references/operations.md) completely. Then:

1. Require the dedicated digest-bound Pilot-14 launcher and deployment.
2. Run provider-free `verify-release` and `doctor --task-id <TASK>`.
3. Require authenticated release/PDF/packet/prompt/runtime/build/atlas/warm-root,
   hardware, predecessor lineage, registry, and condition-isolation evidence.
4. Require the one-shot provider qualification for exact formalizer/auditor
   models, schemas, Code Mode host, and inherited warm fork.
5. Stop on any failed gate. Never fall back to legacy runners or launchers.

Installing or qualifying does not authorize an official pair. Never regenerate
hashes or edit controlled inputs during admission or measurement.

## Preserve the treatment

N and L receive byte-identical PDFs, packets, task prompts, Lean, and Mathlib.
N starts fresh and must have no NumStability bytes, index, history, path, or
environment value.

L forks the one inherited scout root and adds frozen NumStability source/OLean,
`/library-index`, and protected `LIBRARY_GUIDE.md`. It must query the atlas
before recursively scanning source, prefer compatible library declarations and
proofs, and define local replacements only for material semantic mismatches.
Never expose task identities during scouting or use an earlier task child as a
new root.

## Enforce the attempt/audit loop

Use one persistent formalizer conversation per condition and at most four
immutable submissions. Every frozen submission consumes a slot.

For each attempt: meter the task/repair turn through command quiescence and
candidate freeze; validate a fresh copy off-clock; extract the complete
target-type dependency dossier; record private uptake telemetry; run fresh
blind/direct/round-trip auditors; adjudicate every trigger; and, if unfaithful,
send only neutral mismatch feedback to the same conversation when metering
resumes.

Blind and direct judges must each cover every Dxxx dependency, S01-S16, and both
implication directions. Equivalent and genuine full-domain strengthenings are
faithful. Weaker, different, vacuous, restricted, or partial-domain candidates
are unfaithful. Final semantic outcomes are binary; infrastructure incidents
remain separate.

Use 18,000 cumulative active seconds per condition and no token cap. Preserve
exact provider usage and report net-new tokens as the primary token measure.
Scout, validation, dossier, and audit costs are logged separately and excluded.

## Execute and report fail closed

Use only the commands in the operations reference. Never delete, overwrite,
reuse, or mutate task slots, ledgers, audit decisions, or run directories.
Reissue `run` only at a controller-advertised resumable boundary. Stop on missing
telemetry, changed hashes, isolation failure, audit incident, or unsupported
state.

Report observable evidence: task/pair identity, order, statuses, submissions,
active time, exact and net-new tokens, line/declaration counts, treatment uptake,
validation/audit overhead, and artifact paths. Never request or claim hidden
chain-of-thought.

For the primary campaign, call `evaluate-gate` only after all four frozen tasks.
Passing requires both conditions faithful on all four, at least three L time
wins, and at least 20% median reductions in both active time and net-new tokens.
Failure requires a new pilot, not reruns or post-hoc task selection.
