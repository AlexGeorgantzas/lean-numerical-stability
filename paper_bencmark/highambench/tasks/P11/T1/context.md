## Local context and statement

For the first CGS-P column, the paper writes the factorization residual as the
action of a small matrix `G₁` on the input column and bounds its Euclidean norm
by `epsilon` times the input norm. The target states the same finite action
estimate using a Frobenius certificate for `G`, which directly dominates its
operator action.
